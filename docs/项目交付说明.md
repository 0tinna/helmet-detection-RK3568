# 项目交付说明（v4-r2）

**交付日期：2026-11-15。代码版本已冻结，当前工作进入资料维护与成果使用阶段。** 本文件回答交付了什么、怎样使用、验证到哪里；原开发任务和初步完成百分比归入历史资料。

项目在 ATK-DLRK3568 上使用现成社区 YOLOv5 模型，通过 USB 摄像头和 RKNNLite 完成安全帽头部检测。Qt Quick 本地 App 提供全屏预览、开始/停止、后台常驻、同实例唤回和 WiFi 操作界面。日常检测在板端运行，无需浏览器、电脑页面或持续外网。

## 4. 交付时保留的限制

以下限制随本次代码交付保留，供使用和论文陈述时参考。可选补验应另建记录，不按旧初稿重新计算代码完成度。

- 日常检测支持应用级离线；OS、Qt、Python、OpenCV、NumPy、RKNNLite 和驱动需预装。
- 正式链接已启动/切页/退出并核验；`systemui` 重载后的实体图标显示与手指点击未记录。
- WiFi 扫描和输入界面已展示；目标网络认证、DHCP、保存与失败恢复未实测。
- 已验证完整 ZIP 复制到新根；U盘安装、无线 OTA 和无人值守更新未实测。
- 相机常驻 gate 为 180 秒短测。独立供电、长期现场、持续显示与内存稳定性、现场声音及事件质量未完成独立验收。
- 两个 200 图来源训练重叠未知且有一张共有照片，最高诊断 mAP50 低于 0.85；独立质量目标和最终模型资格未通过。
- 无检测或检测不可用都不能保证现场全员戴帽；当前系统没有工业安全认证结论。

未来如增加功能、改变配置或补做现场试验，应新建版本与实验记录。旧成功、失败和已知限制保留原身份。
