# 项目交付说明（v6-r2）

**交付日期：2026-11-17，版本 tag：`native-app-v6-r2`。** 本版在 v6-r1 的精确二进制预览、双 Image、`8091` 手机内网查看、BusyBox 开机待机和完整常驻生命周期上，修复“回到桌面后再次点图标闪退”的窗口可见性冲突，增加空闲输入源自动刷新，并完成全新 ZIP、板端根和项目自有入口迁移。本文回答当前功能、使用、版本身份与验证范围；原初稿百分比和训练设想保留为历史。

项目在 ATK-DLRK3568 上使用现成社区 YOLOv5 模型，通过 USB 摄像头和 RKNNLite 完成安全帽头部检测。Qt Quick 本地 App 提供全屏预览、开始/停止、后台常驻、同实例唤回和 WiFi 操作界面。日常检测在板端运行，无需开发板浏览器、电脑页面或持续外网；同一内网手机可选访问 `8091` 只读页面。

## 3. 关键验证及证据

本轮 [v6-r2 报告](experiments/2026-11-17/native-app-v6-r2/report.md)完成窗口可见性修复、输入源自动刷新、五轮程序化隐藏/唤回和最终入口验收：同一 session/UI instance/PID 下帧号 `51→132→212→264→345→377`，完整退出收据通过。当前没有 USB UVC 节点，真实热插拔仍待现场验证。

## 4. 交付时保留的限制

- 日常检测支持应用级离线；OS、Qt/Wayland、Python、OpenCV、NumPy、RKNNLite 和驱动需预装。完整 ZIP 不是空白板系统镜像。
- 更新使用完整包复制到新隔离根；U 盘安装、无线 OTA 和无人值守更新未实测。
- init 已迁移到 v6-r2 并完成后台启动、双图标复用、正常退出和再次启动验收；实际整机重启后无人提前打开 App 的纯自动后台流程仍需单独现场记录。
- 厂商主界面启动时读取 `/opt/ui/src/ATK-DLRK3568/apk3.cfg`；本项目入口和 desktop 已迁移，但未自动重启 `systemui`。重启后的实体图标显示与手指点击未记录。
- WiFi 扫描和输入界面已有历史证据；目标网络认证、DHCP、保存与失败恢复未实测。
- v6-r2 当前枚举不到 USB UVC 节点，未完成真实热插拔、物理摄像头 FPS、板屏人工连续性和运行中拔线 TTL。历史 v4/v5 物理证据保留原版本身份。
- 当前回放为 180 秒；长期现场、独立供电、持续显示、内存稳定性、现场声音与业务事件质量未完成独立验收。
- 两个 200 图来源训练重叠未知且有一张共有照片，最高诊断 mAP50 低于 0.85；独立质量目标和最终模型资格未通过。
- 无检测或检测不可用都不能保证现场全员戴帽；当前系统没有工业安全认证结论。

未来如增加功能、改变配置或补做现场试验，应新建版本与实验记录。旧成功、失败和已知限制保留原身份。
