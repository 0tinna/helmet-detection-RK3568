# 板端App后台运行手册 v4-r2（已验收运行包）

2026年11月15日。本手册对应当前[v4-r2 Phase 2终验](../experiments/2026-11-15/native-app-usability-v4-phase2-1/report.md)和已冻结的[v4-r2发布清单](../experiments/2026-11-15/native-app/bundle-manifest-v4-r2.json)。日常操作摘要见[板端App使用手册](板端App使用手册.md)，安装和入口迁移见[离线更新与图标安装 v4-r2](离线更新与图标安装-v4.md)。历史v3包和安装记录保留原身份。

这是 RK3568 Linux 上的 Qt 本地应用，不是 Android APK。目标日常方式是板屏点击图标、本地模型检测，不需要浏览器、外网或永久连接电脑。它仍需要兼容 Linux、Python、OpenCV、NumPy、RKNNLite、Qt/qmlscene，以及供电、显示和实际输入条件；应用级离线与空白板卡系统安装不同。断 USB 后独立供电、触摸和实际屏幕体验仍待现场确认。

## 1 两个图标与运行状态

v4-r2正式安装根为 `/userdata/helmet-validation/20261115-native-app-v4-r2-local-2`。四个本项目拥有的入口链接和两个desktop已迁移并备份；“安全帽检测”打开检测页，“Wi-Fi 设置”打开无线页，进入任一页不会自动开始检测或连接网络。厂商主界面尚未重载，因此实体图标的最终显示和手指点击仍需人工确认。

| 状态/操作 | 预期行为 | 用户下一步 |
| --- | --- | --- |
| 首次点击任一图标 | 启动一个后台实例，显示对应页；检测未开始 | 手动选择模型、输入和配置，或进行 WiFi 操作 |
| 点击“开始检测” | 使用所选实际输入和模型运行 | 核对状态与新鲜画面 |
| 回到桌面或关闭窗口 | 隐藏界面，已开始的检测继续；隐藏时暂停画面刷新 | 再点任一图标打开所需页 |
| 再次点击图标 | 复用同一后台和检测会话，恢复实际配置，等待新鲜预览 | 不需要重复点击开始 |
| 点击“停止检测” | 仅请求停止本次检测，后台 App 保留 | 等停止完成后换输入/模型或刷新输入 |
| 点击“退出应用” | 请求停止检测及 WiFi 事务，进入不可逆“清理中” | 等完整退出确认；此时不能重开、启动或更新 |
| 界面意外消失 | 不等同于完整退出；设计要求保留正在运行的检测 | 再点图标；若提示旧所有者仍运行/清理中，保留状态排障 |

显示请求已受理不保证物理屏幕已获得焦点；需现场观察窗口。退出已受理、窗口消失或启动客户端返回，也都不代表 SDK、相机、网络事务及后台进程已经释放。后台运行不代表断电后继续，也不包含开机自动开始检测或自动恢复 NPU。

## 2 手动开始与回到桌面

1. 点击“安全帽检测”，等待本地模型和输入列表。选择明确的模型及输入；“回放演示”是安装的图片或录像，“未验收设备”仅表示发现节点。
2. 选择回放/响应配置，再点击“开始检测”。回放请求节奏 10 FPS、响应请求节奏 20 FPS，不能当作相机、检测或屏幕的实测 FPS。默认列表第一项可能是原 640 模型，不代表最终模型已经选定。
3. 核对界面实际模型、输入、运行状态和画面。`person` 表示裸头，`hat` 表示戴帽头部。App 工作点为 conf 0.35、NMS 0.45、skip 0、TTL 1 秒；相机默认请求 640×480。CLI 诊断运行的 conf 0.25 属于另一工作点。
4. 点击“回到桌面”或关闭窗口。检测继续，隐藏期间不维持预览解码。再次点击任一图标时恢复当前实际配置和同一检测 generation；界面先清除旧预览，再等新鲜匹配结果，不把旧图呈为刚采集的帧。
5. 更换输入或模型前点击“停止检测”，等真实停止完成后再选择。没有结果、断流或过期时显示未知/不可用证据；无检测不能证明全员戴帽。捕获、检测、输出与显示速率分别解释。

有效报警截图及sidecar使用本轮根下的`results/app-snapshots/`。没有文件不能补写保存成功。App不因后台功能新增训练、微调、屏上全部CLI参数或事件录像按钮。

## 3 新摄像头与刷新输入

首次连接相机，先按[摄像头现场验收](../field-validation/摄像头接入与现场验收.md)确认接口、驱动、capture 节点和实际格式。新的[接入进展](../experiments/2026-11-15/摄像头到位与接入准备记录.md)已记录USB `1bcf:0b09`/`UNIQUESKY_CAR_CAMERA`：本次 `/dev/video10` 为uvcvideo Video Capture、`/dev/video11`为metadata，取得90帧640×480/MJPG真帧且采集release完成。另一次416/.35/.45/skip0/TTL1/no-display的12秒既有CLI核心短验完成，174检测/173输出；7个输出含预测目标，正确性未标注。它支持相机采集/推理/新鲜核心输出，不证明v4 App屏幕、后台或精度。此前未枚举观察保留原时点；节点编号可变，不把内部ISP0–9或metadata11当实际图像源。

检测空闲时点击“刷新输入”，让新设备进入候选列表；重新显示窗口也会刷新候选输入。刷新不自动开始检测，不覆盖运行中的实际输入、模型或 generation。当前运行摄像头已拔出时，应仍显示其身份和不可用状态，不能自动显示默认 `1.jpg` 冒充相机。空闲时原选择已消失，应明确重选后才能开始。

v4-r2已用`/dev/video10`完成App连续画面、720×1280全屏、运行中物理拔线后约100 ms清空、后台继续检测、再次唤回和196.67秒连续检测。长期相机运行、断USB独立供电和现场安装条件仍另验。回放后台长跑不能补成物理相机长期验收；标称FPS和默认请求尺寸不能替代实际协商结果。当前不承诺屏上相机格式/FPS控件。

## 4 手动 WiFi

1. 点击“Wi-Fi 设置”，查看当前 SSID、状态与 IP，再手动扫描。默认扫描总等待 20 秒、单条命令 2 秒；扫描中等待，不反复点击。
2. 选择扫描到的网络，或输入隐藏 SSID。支持开放网络和有 RSN/CCMP 选项的 WPA2 个人网络；不回退旧 WPA/TKIP，不把 WPA3、企业认证、WEP、OWE 或未知认证当开放网络。
3. WPA2 输入密码；开放网络保持密码为空。屏幕键盘支持字母、数字、符号、空格和退格，不承诺中文拼音；中文扫描 SSID可直接选择。默认遮掩密码，现场截图/录像避免拍进口令。
4. 需要持久保存时明确勾选“保存网络”，再点击连接。默认不保存；连接预算 20 秒，失败回滚预算 5 秒。以新 SSID、认证完成和可用地址判断连接，保存失败不能当作已保存。

打开WiFi页或扫描不会自动联网。手动连接可能调整该无线接口的地址、路由和DNS，导致现有SSH中断；失败后查看回滚状态，不删除原网络清单。真实SSID列表与密码键盘已经显示，但实际关联、DHCP、保存和失败恢复仍待现场验证，扫描列表不是连接成功证据。退出应用会请求结束当前WiFi事务，回滚未完成时仍保留清理状态。

## 5 完整退出、更新与排障

日常回桌面继续运行；维护前必须选“退出应用”，等所有实际资源终态。共享协调目录`/userdata/helmet-validation/resident-state`记录应用所有者，属于App管理，不是用户可递归删除的缓存。即使后台管理者意外退出，只要旧服务/lease仍活着，就应拒绝第二实例；不要删锁、强杀线程或覆盖代码来“解锁”。v4-r2正常UI退出已记录`cleanup_completed=true`、`resource_lease_released=true`和`service_exit=0`；退出受理或窗口消失本身不算清理完成。

更新按[离线更新与图标安装 v4-r2](离线更新与图标安装-v4.md)进行。供排障保留实际版本、应用根、错误时间、输入/模型标识、状态截图、退出进度与非敏感日志。不要导出密码、派生PSK、会话token、私钥或私有QML包装文件。

图标没有出现时，核对入口收据并由用户正常重新加载厂商主界面或下次开机观察，不强杀桌面。无图时先看输入身份和过期/断流状态。一直清理时保留旧所有者与日志；HTTP 失联不能证明完整退出。
