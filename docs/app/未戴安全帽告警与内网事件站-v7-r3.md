# 未戴安全帽告警与直接内网事件站 v7-r3

**版本：** `20261124-v7-r3`  
**tag：** `native-app-v7-r3`  
**板端根：** `/userdata/helmet-validation/20261124-native-app-v7-r3`

## 1. 使用入口

让手机、平板或电脑连接与开发板相同的可互通 Wi-Fi/局域网，然后直接打开：

```text
http://开发板内网IP:8092/
```

不需要登录，不需要邀请链接，不需要 Cookie，也不需要创建邮件或 SMTP
配置。页面只接受 RFC1918 私有 IPv4 或回环来源；禁止把 `8091`、`8092`
映射到公网，也不建议通过手机热点做端口转发。

`8091` 仍是实时只读预览。`8092` 只展示当前检测/告警状态和已经落盘的
未戴安全帽证据，不提供实时画面、摄像头控制、检测启动、Wi-Fi 设置或退出
按钮。

## 2. 页面内容

首页顶部独立展示当前状态：

| 状态 | 含义 |
| --- | --- |
| `DANGER // NO HAT` | 最新有效报警窗口确认存在未戴安全帽头部 |
| `CLEAR // HAT DETECTED` | 最新有效报警窗口没有持续未戴帽危险 |
| `WATCH // ALERT WINDOW` | 危险目标正在进入判定窗口 |
| `UNKNOWN // NO FRESH FRAME` | 输入无效、断流或结果过期，不能判断安全状态 |
| `STANDBY` | 检测尚未启动 |

当前状态与历史记录分开表达。证据库为空时页面显示“尚未记录未戴安全帽
事件”，这不能解释为现场安全。

每条报警记录包含：

- 带检测框的 JPEG 证据照片。
- 上海时区发生时间。
- 事件 ID、检测帧号和可见未戴帽头部数量。
- 只读媒体地址 `/events/<event-id>.jpg`。
- 按日期筛选和较早记录分页。

## 3. 直接 HTTP 接口

| 路由 | 用途 |
| --- | --- |
| `/`、`/events` | 直接返回赛博朋克告警/安全看板 |
| `/alerts` | 兼容旧书签，`302` 跳转到 `/` |
| `/api/events` | 只读事件 JSON，支持 `limit`、`before`、`day` |
| `/api/status` | 当前告警、检测、存储和 LAN 查看器状态 |
| `/events/<event-id>.jpg` | 已保存报警证据照片 |
| `/healthz` | 最小健康检查 |

所有修改方法返回 `405`。接口不返回公网 IP、文件系统绝对路径、账户地址、
凭据或异常正文。

## 4. 存储与清理

| 项目 | 默认值 |
| --- | --- |
| 事件保留 | 7 天 |
| 事件文件总上限 | 256 MiB |
| 最大事件数 | 5000 |
| 磁盘最低余量 | 128 MiB |
| 清理时机 | 启动时和每小时 |

照片与 JSON 位于 `results/helmet-events/YYYY/MM/DD/`，使用同目录临时文件、
`flush`、`fsync` 和原子替换发布。磁盘低于安全余量时停止新增证据，已有
文件不会被盲目删除。

## 5. 部署与状态

宿主机验证：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m unittest discover -s helmet/tests -v
```

板端只读检查：

```sh
wget -qO- http://127.0.0.1:8092/healthz
wget -qO- http://127.0.0.1:8092/api/status
```

`healthz` 正常返回 `ok`。API 的 `viewer.scope` 应为 `lan`，并包含当前
`alarm_state` 与 `frame_id`。

## 6. 边界与未验项

- 本版支持同一可信内网直接查看，不支持公网 IP、公网端口映射或蜂窝访问。
- 局域网来源检查和只读路由不能替代 Wi-Fi 密码、路由器防火墙和可信设备管理。
- 主机自动测试不能替代真实手机、物理摄像头多人事件、人工拔线 TTL、板屏
  人工闪烁观察、图标触摸和整机重启。
- 本轮真实相机画面没有裸头目标，因此没有为了展示向事件库写入模拟记录；
  `8092` 的空库真相和真实相机通过，实体手机与真实未戴帽人员事件仍未验。
- 空事件库、无检测输入和输入断流都属于“未知是否全员戴帽”，不得写成现场安全。
