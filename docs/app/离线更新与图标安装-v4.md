1. 在旧 App 选择“退出应用”，等检测、相机、WiFi事务、Qt及后台所有者实际结束；新测试实例也需终态。回到桌面、关闭窗口、停止检测或收到退出已受理，都不足以允许更新。
2. 记录现有应用根、源码/包身份和入口目标。共享 `/userdata/helmet-validation/resident-state` 属于 App 所有者；活服务/lease禁止另开或更新，不能递归删除协调目录、锁或旧结果来绕过检查。
3. 把核验过的完整 v4-r2载荷复制到**新的**根。已有根若含活 owner或需保留证据，不覆盖；维护者先确认终态及归档边界。

v4-r2正常UI退出收据必须包含 `cleanup_completed=true`、`resource_lease_released=true` 和 `service_exit=0`。看不到 HTTP 或窗口不能替代所有者/lease终态。遇清理未完成，停止迁移并保留状态排障，不强杀设备线程。
