# 手机内网查看与开机后台启动（v6-r1）

v6-r1 在 v5-r3 的只读 `8091` 页面和 BusyBox 后台入口上，优化了预览二进制传输、Qt 双缓冲、LAN 换图门和常驻状态写入。日常检测仍使用板端模型与摄像头，不需要开发板浏览器、持续外网或 USB 连接电脑。包需要预装 Linux、Qt/Wayland、Python、OpenCV、NumPy、RKNNLite 和驱动。

## 手机访问

手机连接与开发板可互通的同一 WiFi/内网，在浏览器打开：

```text
http://开发板当前IP:8091/
```

本板当前无线地址为 `192.168.1.3`，即：

```text
http://192.168.1.3:8091/
```

地址由 DHCP 和实际网络决定。换网后先看“无线网络”页的当前地址。访客网络、AP 隔离或防火墙可能阻止手机互访。

页面只读，不提供远程开始、停止、WiFi 或退出控制。状态接口为 `/status.json`；图像使用精确 `/frame.jpg?frame_token=...`。浏览器先解码新图，成功后才替换 canvas。非法令牌返回 400；旧帧过期或已淘汰返回 503，不会退回“最新图”。停止检测、断流或超过 1 秒 TTL 后应清空旧图。

2026-11-17 已通过板端自身 WLAN 地址和独立 Windows 主机 HTTP 测试，端口为 `8091`。实体手机的浏览器、触摸和持续显示仍需人工验收。

## 启动行为

| 操作 | 行为 |
| --- | --- |
| 板卡开机 | `/etc/init.d/S99zhelmet-app` 启动后台 resident 与 `8091` 监听，不抢桌面、不自动检测 |
| 点击“安全帽检测” | 显示全屏检测页；若后台已存在则复用同一 session |
| 点击“无线网络” | 显示同一窗口的 WiFi 页，不启动第二个 NPU 实例 |
| 关闭窗口/回桌面 | 进程与检测继续；板屏预览刷新暂停，状态轮询和检测帧号继续 |
| “退出应用”或 init `stop` | 请求真实清理；必须等 session 收据确认进程、socket、HTTP 和 lease 已释放 |
| 再次点击图标或 init `start` | 已退出时建立新 session；仍在运行时复用原实例 |

开机后台启动只建立待机服务。手机页面在未开始检测时显示待机；用户需在板屏选择输入和模型并点击“开始检测”。当前没有自动重启守护循环，用户主动退出后不会被立即拉起。

## 安装与入口

v6-r1 的正式部署根：

```text
/userdata/helmet-validation/20261117-native-app-v6-r1
```

对应最终包为 `dist/helmet-native-app-20261117-v6-r1.zip`，39,234,949 B，SHA256 `8b51ab3dded637e02b543051a8f77427df91359b12fb6b42187d88b9a33aa726`。40 个载荷、内部/外部 manifest 与五文件 identity 已在板端逐项核验；发布身份见[v6清单](../experiments/2026-11-17/performance-baseline/bundle-manifest-v6-r1.json)。

本项目拥有的入口：

```text
/opt/ui/src/apps/helmet_app
/opt/ui/src/apps/helmet_wifi
/etc/init.d/S99zhelmet-app
```

两份 desktop 位于当前 root 用户的应用目录，指向同一完整根。迁移前备份原链接与 desktop，并核验 `apk3.cfg` SHA。不要覆盖其他厂商应用。厂商主界面在启动时读取 `/opt/ui/src/ATK-DLRK3568/apk3.cfg`；修改图标后需要人工决定是否执行：

```sh
sh /etc/init.d/S50systemui restart
```

本项目不自动重启 `systemui`。

## 维护命令

```sh
sh /etc/init.d/S99zhelmet-app start
sh /etc/init.d/S99zhelmet-app status
sh /etc/init.d/S99zhelmet-app stop
```

`start` 仅确保后台实例存在；`status` 读取当前 resident/HTTP/LAN 状态；`stop` 等待同 session 的真实终端收据。进程未退出、lease 未释放或收据缺失时返回非零，不能把“请求已受理”写成“已退出”。
