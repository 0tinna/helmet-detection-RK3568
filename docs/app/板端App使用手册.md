# 板端App使用手册

更新日期：2026-11-17。版本与交付限制见[项目交付说明](../项目交付说明.md)。

本 App 让 RK3568 直接在板屏上启动安全帽检测，并在需要联网时手动连接 WiFi。当前版本为 **v6-r2**：日常检测使用板端模型和摄像头，可以离线运行；同一内网的手机还可通过 `http://板端IP:8091/` 查看同一实例。板屏操作无需浏览器或 USB 连接电脑。

当前使用已安装的Qt、Python、OpenCV、NumPy和RKNNLite，不训练或微调模型。v6-r2 沿用 v6-r1 的小元数据加精确二进制 JPEG、双 Image 有效画面保留和常驻状态写合并，并修复回桌面后再次点图标可能因窗口可见性双绑定而闪退的问题；空闲页还会定期刷新输入源。v6-r1 同条件回放中可见态检测约 7.80 FPS、呈现约 4.40 FPS、Qt CPU 33.25%，完整记录见[2026-11-17 性能报告](../experiments/2026-11-17/performance-baseline/report.md)。物理 USB 摄像头、板屏人工连续性和拔线 TTL 仍以历史及后续现场记录为准。

## 1 当前安装位置和入口

本手册对应 v6-r2 的完整安装布局：

```text
/userdata/helmet-validation/20261117-native-app-v6-r2
  src/app/              本机服务 WiFi后端 Qt界面与启动器
  src/                  共用检测流水线与后处理
  models/               已有RKNN模型
  input/                回放演示输入
  results/              报警截图等本轮结果
  app-state/            私有会话目录 启动锁与日志
  vendor-entry/         厂商桌面启动文件和配置备份
```

点击“安全帽检测”进入检测页，点击“无线网络”或“Wi-Fi 设置”进入 WiFi 页。固定入口为 `/opt/ui/src/apps/helmet_app` 和 `helmet_wifi`，两个 desktop 使用同一完整根；开机入口为 `/etc/init.d/S99zhelmet-app`。迁移、备份和 `systemui` 重载见[内网及开机指南](手机内网查看与开机启动-v6.md)，是否重启桌面由人工决定。

历史入口 v1–v4-r2 和本轮候选包均保留原身份。v4-r2 迁移备份仍在旧根 `vendor-entry/icon-migration-r2-*`；本轮备份位于独立实验目录，实际路径以迁移收据为准。回退前先正常退出新实例，再核对备份及目标。

当前启动器一次只允许一个resident会话。点“回到桌面”或关闭窗口只隐藏窗口，manager、service、Qt和检测继续运行；再次点任一图标复用同一session，只切换检测/WiFi页。点“退出应用”才请求完整清理。显示“仍在清理”时等待，不要为了重开强杀NPU或回滚网络的线程。

## 2 在屏幕上开始离线检测

1. 打开“安全帽检测”。等待本地服务和模型/输入列表出现。
2. 选择已安装模型和输入。名称带“回放演示”的输入是已有图片或录像；“实时摄像头 UNIQUESKY_CAR_CAMERA”对应 USB 相机。空闲页约每 2 秒自动重扫输入源，也可点“刷新输入”立即扫描；没有 USB 摄像头时会显示提示。枚举到名称不等于新设备已经通过抓帧验收。
3. 选择回放配置。默认回放请求节奏10 FPS；响应测试为20 FPS请求节奏，均不是实测摄像头帧率或完整检测性能。
4. 点击“开始检测”。查看对应原帧画面、检测框、状态、原帧编号和独立检测FPS。
5. 点击“停止检测”，等停止完成后再切换模型或输入；停止后预览区恢复“点击开始检测”。
6. 点“回到桌面”可继续后台检测；再次打开会回到当前配置。需要结束进程时使用“退出应用”，并核对退出结果。

当前模型默认值来自已安装列表的第一项。v6 性能对照固定使用 `helmet_416x416.rknn`；该结果不能自动归给默认640或其他模型。模型的`person`类别表示裸头，`hat`表示戴帽头部。现有App复用固定conf0.35、NMS0.45、skip0、TTL1秒的流水线，不把0.25诊断指标当作同一运行工作点。

有新鲜对应结果时显示检测画面；断流、过期、停止或启动/恢复等待时清除旧图。运行中断流保留状态原因，预览区不反复出现“点击开始检测”。无检测表示当前有效帧未找到目标，不能推断全员戴帽。屏上 FPS 是滑窗独立检测速率，完整会话、采集、输出和显示速率各有计时边界。

历史相机采集节点为 `/dev/video10`，`/dev/video11` 是元数据；设备重插后节点可能改变。新设备的节点与格式确认见[摄像头现场步骤](../field-validation/摄像头接入与现场验收.md)。v6 当前预览采用二进制 JPEG 与双 Image 缓冲；2026-11-17 的请求、解码、呈现一一闭合与 180 秒回放见性能报告，物理板屏连续性仍需人工确认。

## 3 保存与结果查阅

当前App调用共用Pipeline，报警截图保存到本轮根下`results/app-snapshots/`，对应sidecar记录原帧、模型和时间。只有有效新鲜证据会保存；没有文件应先查报警窗口、状态、路径及磁盘，不补写保存成功。

App当前没有屏上参数编辑、会话日志导出按钮、音量设置或事件录像开关。需要完整实验JSONL、资源sidecar、音频或MPP事件录像时，按[完整手册的CLI步骤](../项目蓝图与完整手册.md)另开隔离实验；不要将CLI功能全部描述为已在App界面暴露。

每次启动会在`app-state/session-.../`保留服务/界面日志、进程记录和退出结果。运行中的私有令牌及QML包装文件不是用户资料，不能公开复制；正常完整退出后启动器删除敏感会话文件。服务不记录带密码的HTTP请求或口令。

## 4 手动连接WiFi

当前默认扫描总等待 20 秒、单条命令最多 2 秒。扫描中等待结果；超时或失败后检查无线模块和环境，再手动重试。这个等待预算继承自 v3，历史 v2 的 8 秒超时记录仍保留。

联网只在用户主动点击“连接所选网络”时发生。检测本身不以联网为启动前提，进入WiFi页或扫描不会自动切换当前网络。

1. 打开Wi-Fi设置，查看当前SSID、连接状态和IP。
2. 点击“扫描附近 Wi-Fi”，等待附近网络名称、信号dBm与安全类型列表。
3. 点击支持的网络；也可输入隐藏网络名称。扫描列表里的中文SSID按UTF8显示，SSID上限为32字节，字符数不能替代字节数。
4. WPA2个人网络输入密码，开放网络选择“开放网络（无密码）”并保持密码为空。部分路由器同时广播旧WPA/TKIP与WPA2，只有明确提供WPA2/RSN的PSK加CCMP选项时才支持，连接仍强制RSN和CCMP，不回退旧算法。仅旧WPA/TKIP、WPA3、企业认证、WEP、OWE或未知认证不支持，不能按开放网络连接。
5. 点击SSID或密码框使用内置屏幕键盘。键盘支持字母大小写、数字、符号、空格和退格；默认密码遮掩，“显示密码”只供用户检查，避免让现场录像记录口令。键盘不承诺中文拼音输入；已扫描到的中文SSID可直接选择。
6. 如希望下次由wpa配置保留此网络，明确勾选“保存网络”；默认不勾选。
7. 点击连接，等待成功或失败状态。连接中不重复点击扫描或连接；成功须匹配新SSID、认证完成并获取可用地址。

密码在本机处理，不写入普通请求日志。勾选“保存网络”会请求持久保存网络配置及派生 PSK；保存失败不能当作已保存。扫描和密码键盘已有真实界面记录，实际目标网络认证、DHCP、保存与失败恢复仍未实测。

手动连接可能更新无线接口的地址、路由和 DNS，并中断原 SSH 连接。成功应以目标 SSID、认证完成和可用地址判断；不要把扫描列表当作连接成功。

连接失败会删除本次新建网络条目，并尝试恢复原选择和每条既有网络启用状态。DHCP或恢复失败、没有可恢复旧地址基线时，应按界面失败信息检查原网络，不将“已恢复配置”解读为所有地址/DNS都已回到原状。不要因失败手动删除原有网络清单，先保留状态和日志。

## 5 日常启动和更新的区别

安装完成、兼容系统依赖已具备后，板端启动App和本地检测不需要电脑。U盘或电脑只用于首次复制、后续更新及排障；需要在线取文件时，在板屏先手动连接WiFi，再使用设备原有更新途径。

开机入口配置后台待机及 `8091` 监听，不自动检测。点图标后显示已有实例，手动开始；关窗/回桌面保留检测与内网。v6 已完成无窗口到图标唤回、同 session 复用、WiFi/检测页切换、完整退出和退出后重启的软件验收；实际整机重启后的纯自动后台启动与实体图标点击仍需现场记录。

当前运行包为[v6-r2 ZIP](../../dist/helmet-native-app-20261117-v6-r2.zip)，精确字节数、SHA 和五文件身份见[外部清单](../experiments/2026-11-17/native-app-v6-r2/bundle-manifest-v6-r2.json)。复制前核对外部 SHA，再整体解压到新根并逐文件校验。兼容 Qt/Linux/RKNN 仍须预装。

当前配置和入口维护按[v6 内网及开机指南](手机内网查看与开机启动-v6.md)操作。[v5 指南](手机内网查看与开机启动-v5.md)与[v4-r2 更新指南](离线更新与图标安装-v4.md)保留旧版本身份。历史包与证据见[实验索引](../experiments/README.md)。

## 7 常见问题

**主界面没有新图标。** 厂商 `apk3.cfg` 在主界面启动时读取；迁移只修改项目入口，不自动重启 `systemui`。人工重载命令为 `sh /etc/init.d/S50systemui restart`，随后检查两枚图标。

**再次打开或提示旧实例仍在。** 正常重复点击应唤回同一后台会话；若提示正在清理，等待完整退出，保留退出记录再排障。

**开始后无图。** 核对当前输入、模型、状态原因和 TTL。新摄像头按[现场步骤](../field-validation/摄像头接入与现场验收.md)确认 capture 节点及格式；空闲页会自动重扫，也可手动刷新。运行中拔线后清空旧画面是预期行为。

**扫描失败或无线状态未知。** 保存当前错误状态，检查无线模块和wpa控制路径是否存在。不能调用厂商带明文密码argv或killall脚本替代App后端。

**关窗后进程仍在。** 常驻模式下关窗只隐藏；结束进程需点“退出应用”。若退出一直清理中，保留设备、网络事务和退出日志；窗口消失或请求受理不能证明资源已释放。

**版本或包不确定。** 以实际SHA、部署manifest、源码和终态记录为准。旧包不含App，HTML开题演示也不是本地Qt应用。

操作摘要见[后台运行手册](板端App后台运行手册-v4.md)，技术与证据总入口见[项目交付说明](../项目交付说明.md)。
