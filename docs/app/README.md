# 板端 App 操作资料

**v7 软件候选版：** [未戴安全帽告警、邮件与公网事件站](未戴安全帽告警、邮件与公网事件站-v7.md)记录 `8092` 事件站、SMTP、动态公网 IP、保留和清理策略。它不开放实时画面，不能与现有无鉴权的 `8091` 内网预览混用；现场验收未完成前，`v6-r2` 仍是稳定基线。

当前版本为 **v6-r2**。它沿用 v6-r1 的精确二进制 JPEG、双 Image、`8091` 手机内网查看、BusyBox 开机待机与常驻生命周期，并修复窗口同时绑定 `visible`/`visibility` 导致“回到桌面后再次点图标闪退”的问题；空闲页每约 2 秒刷新输入源，USB 摄像头晚插入时无需重开 App。日常使用从 App 手册开始，手机和启动维护看 v6 指南；v6-r1 性能报告与本轮可用性修复报告分别引用。
