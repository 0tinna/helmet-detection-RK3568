# 手机内网查看与开机后台启动（v5-r3）

v5-r3 在 v4-r2 原生 App 的基础上增加只读内网页面与 BusyBox 开机后台入口，修复常驻状态文件更新竞争，并要求重复 stop 仍核验原会话的退出收据。应用包需要预装的 Linux、Qt/Wayland、Python、OpenCV、NumPy、RKNNLite 和驱动；检测仍使用本地模型，不要求外网。

## 手机如何访问

手机连接与开发板可互通的同一 WiFi/内网，在浏览器输入：

```text
http://开发板当前IP:8091/
```

本板当前无线地址为 `192.168.1.3`，对应 `http://192.168.1.3:8091/`。地址由实际网络决定，换网或 DHCP 改变地址后需使用新 IP；访客网络或路由器客户端隔离可能阻止设备互访。

开机后台启动后，页面先显示待机。在板屏打开“安全帽检测”，选择“实时摄像头 UNIQUESKY_CAR_CAMERA”和模型，再点击“开始检测”；手机同步显示同一个检测实例的对应帧与状态。回到桌面后检测和内网查看继续，再点图标唤回同一实例。

页面只用于查看，不提供远程开始/停止、WiFi 或退出控制。停止检测后旧画面清除；断流、过期、浏览器连接挂起或解码迟到时也不保留旧图。无检测不能保证全员戴帽。

## 开机、图标与退出

| 操作 | 行为 |
| --- | --- |
| 板卡开机 | `S99zhelmet-app` 启动后台实例与 `8091` 监听；不抢桌面，不自动选择输入或开始检测 |
| 打开任一项目图标 | 复用后台实例，显示检测页或 WiFi 页 |
| 关闭窗口/回桌面 | 保持当前检测与内网服务，暂停板屏预览刷新 |
| 停止检测 | 保留 App/内网待机页，清除旧检测画面 |
| 退出应用 | 正常清理检测、WiFi、两个 HTTP 监听器、Qt 和所有者锁；此后页面暂不可访问 |
| 再次点图标或下次开机 | 启动一个新实例与内网监听器 |

没有自动重启守护循环：主动退出后不会被马上拉起。手机查看属于可信内网的只读视频/状态访问，服务监听 `0.0.0.0:8091`；App 私有令牌控制继续只监听随机 `127.0.0.1` 端口。

## 维护命令

v5-r3 完整包的部署根为 `/userdata/helmet-validation/20261115-native-app-v5-r3-lan-3`。安装使用完整包、新根和逐文件核验，旧根及 ZIP 保留。开机链接：

```text
/etc/init.d/S99zhelmet-app
  → /userdata/helmet-validation/20261115-native-app-v5-r3-lan-3/src/app/autostart.sh
```

已安装链接后，维护者可在板端调用：

```sh
sh /etc/init.d/S99zhelmet-app start
sh /etc/init.d/S99zhelmet-app status
sh /etc/init.d/S99zhelmet-app stop
```

重复 start 仅确保实例存在，不隐藏已打开的窗口或重启检测。stop 请求正常退出，并等待同 session 的退出收据、全部进程结束与锁释放；即使已无进程，同根的旧会话也必须检查收据。未确认或失败返回非零。

验证见[本轮报告](../experiments/2026-11-15/app-lan-autostart/report.md)，文件身份见[发布清单](../experiments/2026-11-15/app-lan-autostart/bundle-manifest-v5-r3.json)。按“systemui 重启由人工决定”的要求，本 agent 未下发重启；最后观察到实际重启及 App 使用/正常退出，但人工图标操作前的纯自动后台启动仍未隔离验收。实体手机、持续显示、触摸和长期现场按各自记录说明。仓库维护手册可以在封包后更新，冻结 ZIP 不回写。
