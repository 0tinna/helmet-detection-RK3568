## 查看或继续开发

```sh
git fetch origin --tags
git show native-app-v5-r3 --no-patch
git switch --detach native-app-v5-r3
```

查看 tag 是固定版本；需要继续改动时，从它创建独立分支：

```sh
git switch -c fix/next-app native-app-v5-r3
```

后续版本建立新 tag，例如 `native-app-v5-r4`。已经发布的 tag 不移动、不覆盖；失败候选保留报告和包身份，未完成验证不使用正式版本标签。整包 SHA、五文件 identity 和 Git commit 各自记录，不能用同一五文件 identity 推断两个 ZIP 相同。

## 板端回退

先通过 App 完整退出并确认所有进程、设备线程和锁释放，再核对目标版本完整 ZIP、清单和旧入口备份；使用新隔离根整体部署，最后迁移项目自有入口/init 链接。`git checkout` 只切换主机文件，不会自动改变已安装板端版本，也不授权覆盖旧根或清理未完成的实例。
