- [x] 最终包洁净安装：47 个载荷哈希与可执行位通过，session/UI/进程复用及 `8091`/`8092` HTTP 边界通过。

## 4. 建议执行顺序

1. 配置私有 `mail.json`，执行 `mail_probe.py`。
2. 使用同一局域网实体手机验证邀请链接和事件页。
3. 使用物理摄像头验证单人、多人、后进入、停留和重入。
4. 执行人工拔摄像头后的板屏 TTL 观察。
5. 最后迁移图标并人工确认板屏触摸与 `systemui` 重启。

任一板端项失败时保留现有成功项并写明具体 run；不能用主机 fake SMTP、回放或
临时 HTTP 测试替代真实邮件、实体手机和物理摄像头结论。
