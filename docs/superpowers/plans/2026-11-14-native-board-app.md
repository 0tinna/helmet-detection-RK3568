# RK3568板屏应用与WiFi接入实施计划

**Goal:** 使用已有Qt和Python，交付无需浏览器的板端检测入口与手动WiFi连接页面。

**Architecture:** Qt Quick界面访问仅本机绑定、令牌保护的Python服务，检测复用Pipeline，WiFi通过wpa_supplicant控制套接字操作。

**Spec:** [板屏设计](../specs/2026-11-14-native-board-app.md)。

## 全局约束

不训练、不改变模型/类/解码/阈值。板端新增文件在/userdata隔离目录。保留现有网络与旧实验，不在自动验证中切换当前WiFi。密码不写日志、参数或响应。App必须在WiFi断开时仍可启动离线检测；摄像头及人工触摸延期。

## 任务

- [x] A WiFi后端：Unix控制协议、状态/扫描、开放/WPA2验证、PSK推导、失败回滚、可选保存及受控DHCP；34项Linux协议/进程测试通过、独立复审批准。真实连接与保存没有自动执行。
- [x] B 本机服务：令牌和来源校验、模型/源白名单、独占Pipeline工作线程、JPEG时效、开始/停止/关闭和WiFi异步动作；源代次/run UUID绑定及输出路径行为测试通过，独立复审批准。
- [x] C Qt界面：检测页、WiFi列表与密码触摸键盘、异步状态、图标入口/启动/部署；真实720像素宽竖屏Qt渲染验证，厂商apk3.cfg已安装两入口并从其实际包装脚本启动退出0。横屏与真实触摸仍未人工确认。
- [x] D 可自动验证的集成：实际板端本机API、真NPU回放与Qt窗口、仅loopback隔离禁网App运行退出0，证据/说明与本地运行包归档。主机215项、板端WiFi34项及service20项按日志报告跳过；不能当实际WiFi连接或摄像头验收。

证据见[App验证清单](../../experiments/2026-11-15/native-app/validation-manifest.json)与[使用手册](../../app/板端App使用手册.md)。主界面下次启动才读取新图标配置，未自动重启；实际点击、触摸、断USB独立供电及WiFi认证/DHCP/保存仍为人工验收。原毕业计划的独立85%、摄像头与最终选型门槛不因此勾选。

## 复审关注

不能因UI隐藏就放弃后端状态检查；口令不能进程序参数或异常；未知安全类型不得降级开放连接；失败回滚不删除现有配置；停止超时不得释放仍在运行的SDK或允许第二个检测worker。
