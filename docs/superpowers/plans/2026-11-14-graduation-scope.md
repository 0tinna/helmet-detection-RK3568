## Global Constraints

- 不训练、不微调、不剪枝、不蒸馏。所有结论必须能追溯到已归档的模型与测量。
- 类别顺序固定 `('person', 'hat')`；数据集类别语义必须与现状一致，否则指标不可解释。
- 测试集必须独立。不得用训练侧图片做测试，不得用测试集调阈值。
- 结果按场景划分 train/val/test，不按随机抽样切分。
- 所有板端写入限定在独立验证目录内；实验结束恢复 NPU governor。
- 保留原始测量，不以修改结论替代留档。

## 数据集选型

| 数据集 | 规模 | 类别 | 格式 | 许可 | 用途 |
| --- | --- | --- | --- | --- | --- |
| SHWD (`njvisionpower/Safety-Helmet-Wearing-Dataset`) | 7581 张；9044 hat、111514 未戴帽头部 | `hat` / `person` | Pascal VOC | 未明确标注，需补引用 | 主测试集（同域上界） |
| Roboflow Hard Hat Workers | 约 7k 张 | `head` / `helmet` / `person` | COCO / YOLO | Public Domain | 跨域验证首选 |
| GDUT-HWD | 约 3.1k 张 | 五色帽 + 无帽 | VOC | 需确认 | 跨域备选 |
| Roboflow Universe hardhat 工程 | 数百至数千 | `hardhat` / `no-hardhat` | COCO 导出 | 多为 CC BY 4.0 | 零改名直接接入 |

**关键风险（数据泄漏）：** 现有模型的类别语义（`person` 实为"未戴帽头部"而非整个行人）与 SHWD 完全一致，原始模型很可能训自 SHWD。直接以其图片作测试集会显著高估指标。

**对策：** 相对比较仍然有效（五尺寸测同一测试集），绝对数值标注为"同域上界"；另用不同来源数据集给出跨域衰减率。论文写作必须披露这一点。

## 格式硬约束

`eval_map.py` 的实际要求，不满足则无法运行：

1. 标注必须是 COCO 格式，文件名固定为 `_annotations.coco.json`。
2. 类别名必须是 `hardhat` 与 `no-hardhat`（脚本内映射 `hardhat→hat(1)`、`no-hardhat→person(0)`）。
3. VOC 数据集须先转 COCO 并完成类别重命名，这是第一件要写的小工具。

另注：SHWD 类别严重不平衡（约 1:12），`hat` 与"未戴帽"必须分别报指标，只报单一 mAP 会掩盖未戴帽召回的真实表现。

## Tasks

### P0 摄像头与屏显闭环（前置）

依赖：无。C 级任务依赖本项。

- [ ] 枚举并确认摄像头节点与真实采集格式（`v4l2-ctl --list-devices`、各节点 name）。
- [ ] 实测分辨率、像素格式、协商帧率、应用实际帧率，产出参数表。
- [ ] 屏上实时显示：画面 + 检测框 + 未戴帽横幅。Wayland 图片窗口 API 已退出 0，回放标注与 Web 预览已验证；人工看屏及真实摄像头显示延期。
- [x] 帧与结果绑定：每帧携带时间戳；旧结果不得贴到新帧，过期状态可见。
- [x] 报警状态机：首次触发、持续场景限频、故障时禁止复用旧报警、恢复后自愈。
- [x] 事件留痕：报警保存截图、时间戳、置信度、类别；源过期/故障禁止误导性保存。
- [x] 实现 `--save-interval` 对应分支，真实回放定时截图与失败处理已验证。

**验收：** 真实摄像头连续运行可出图；断流后进入明确故障态；事件可回查。

### S 级 精度评估（核心）

依赖：Linux x86 或板端推理；标注数据。无 GPU 需求。

- [ ] S1 独立场景测试集门槛：完整 SHWD 源归档、两来源固定 200 图诊断接入、VOC→COCO、来源/许可/坐标/difficult/原名映射 manifest 均完成；源缺少可靠 scene ID，现有社区模型训练重叠未知，不能勾选“独立场景测试集”。分组工具已实现并验证，当前各保留一个 scene-unknown 组，不伪造随机 train/val/test。
- [x] S2 五尺寸评估：六个模型（原模型 + 五尺寸）的 per-class AP@0.5、recall、precision、F1，12 次完整诊断结果与 200/200 图像身份均已核验。
- [x] S3 误检漏检可视化：每模型固定抽样出图，红色=漏检、绿色=正确、黄色=误检。
- [x] S4 小目标专项：按 GT 框面积分桶（小/中/大），曲线、计数与匹配规则留档。
- [x] S5 第二来源诊断验证：同模型同阈值复测并报告百分点/相对变化，包含提升与下降，不强称衰减；已知一张照片重叠与训练独立性 unknown 保留。

### A 级 长跑稳定性与故障注入

依赖：P0。

- [x] A1 当前冻结代码的 30 分钟真实 NPU 视频回放连续性已验证：[longrun-final manifest](../../experiments/2026-11-14/longrun-final/manifest.json)、[严格核查结果](../../experiments/2026-11-14/longrun-final/verification.json)、[验证日志](../../experiments/2026-11-14/longrun-final-verification.log)及延迟/内存/温度/NPU曲线均归档。session active 1800.064616 秒，17,630 次捕获、17,591 次检测、17,590 次输出、39 次覆盖、结束时1个待输出结果，0读失败/推理失败。检测9.772426970 FPS，**10 FPS目标未达**；阈值为conf .35/NMS .45，与.25精度实验口径区分。五个实际Pipeline运行源码及单独验证器哈希与冻结源码一致，五模块与final包一致；严格验证含SSH存活观察，连续性/帧绑定/新鲜度通过。RSS实测起始75,624,448、结束136,167,424、峰值137,248,768字节，不宣称零增长/无泄漏。历史旧代码1800.038秒/17,559检测/9.754817 FPS及其资源证据保留；新长跑仍是视频回放，不替代物理摄像头、显示或全部CLI/Web输出路径验收。
- [x] A2 可行故障注入：四场真实 SDK 委托/源中断/坏模型/坏源及新 SSH 会话同 PID 存活证据完成。检测 worker 内异常替代不安全的 Python 异步外杀线程；多模型分别启动替代未批准的运行期热切换。`physical_thread_termination=false`、runtime hot-swap 未测，摄像头拔插延期。旧失败组与新组直接清理证据均保留。
