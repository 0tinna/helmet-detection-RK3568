# Acquired annotated sources, 2026-11-14

Both evaluations use fixed 200-image source-defined subsets. They are **subset metrics**, not complete-dataset metrics. No model scores were used to select images, inspect geometry, detect shared photographs, or choose classes. Community-model training overlap is unknown for both sources.

## SHWD diagnostic subset

Original repository: <https://github.com/njvisionpower/Safety-Helmet-Wearing-Dataset>. The exact commit is recorded in `datasets/provenance/shwd-upstream-commit.json`; original README and MIT license are retained beside it. The upstream README identifies `hat` as a helmet/head positive and `person` as a normal head negative, and acknowledges SCUT-HEAD for some negatives.

Original dataset URL linked by that README: <https://drive.google.com/open?id=1qWm7rrwvjAWs1slymbrLaCf7Q-wnGLEX>. Original archive `VOC2028.zip`, HTTP total 1,117,970,537 bytes, Last-Modified `Fri, 16 Aug 2019 11:03:14 GMT`. Acquired archive index contains 15,171 entries, including 7,581 JPEGs and 7,581 annotations. The original `ImageSets/Main/test.txt` has 1,517 IDs. The acquired subset is exactly its first 200 IDs in original order, declared in `shwd-selection.json` before inference. This selection is reproducible but is not representative random sampling: early numeric IDs are helmet-heavy (198/200 images have hat boxes). No full-dataset accuracy claim is appropriate.

All 200 original image/XML pairs and four original split files were acquired via exact HTTP ZIP byte ranges. `shwd-original-central-directory.bin`, archive index, original compressed member byte ranges under `datasets/raw/shwd-archive-ranges/`, per-file SHA256 and ZIP CRC32 are retained. `shwd-member-integrity.json` confirms 404/404 original extracted members pass both checks. This is authentic extraction from the original upstream archive, not a Kaggle reannotation. The full original archive transfer subsequently completed at 1,117,970,537 bytes; SHA256 is `2f6c5c347b778271bc8b27c2d61b731fc5fb8cdb4f45fce583dd2f82e6a46401`, recorded in `datasets/provenance/shwd-original-full-archive.json`. Its complete ZIP inventory was read successfully. Evaluations still use only the fixed 200-image subset and do not become full-dataset metrics.

Upstream repository MIT is not evidence that every contributed image is MIT. Original README states Google/Baidu-sourced positives and SCUT-HEAD-derived negatives. SCUT-HEAD upstream README explicitly states: **“The SCUT-HEAD database is free to the academic community for research purpose usage only.”** That README and commit metadata are retained. Image search/copyright permissions cannot be established from the repo license. Keep this local academic experiment's raw images separate from distributable code and do not claim unrestricted republication rights. See `scut-head-README.md` and `shwd-upstream-LICENSE`.

No archive was downloaded or represented as acquired. Original class semantics are helmet/head/person; manually verified helmet and bare head boxes. Two original annotated public distributions do not imply disjoint original photographs. No exact-byte duplicates were found. Keep both in the fixed primary200-image subsets, group them together if any pooled paired analysis uses both, and optionally report a separate199-image Hard Hat sensitivity result excluding only the already identified shared photo. This optional exclusion uses input photo evidence, not model performance. It does not prove the remaining images independent. See `manual-scene-review.json` and `acquired-duplicate-review.json`.

The correct label for Hard Hat Workers is **“cross-source, training overlap unknown; one known acquired shared photograph with SHWD”**. For SHWD use **“diagnostic source test subset, community training overlap unknown”**. Neither is certified held-out from the community model's training.

## Coordinate and scene contract

`coordinate-and-mapping-contract.json` records source-specific assumptions. SHWD follows canonical1-based inclusive VOC: subtract1 from xmin/ymin and add1 in width/height. All998acquired SHWD boxes start at≥1. Hard Hat Workers has143of991boxes starting at0, so preserve0-based edges and use `width=xmax-xmin`, `height=ymax-ymin`. The source export does not prove whether maximum coordinates are inclusive; this fixed conventional interpretation must be disclosed, applied equally to all models, and retained with raw XML.

Original filename, XML path, image hash, dHash, dimensions and original classes are in each `*-image-inventory.csv`. The original sources lack camera/video/location/capture-session IDs. These inventories provide auditability; they cannot create independent scene labels. Only the visually confirmed shared-photo pair has a justified common scene group. Report image-level paired uncertainty if scene groups are unavailable, and explicitly disclose that limit. Random filename splits or byte-hash inequality do not establish scene independence.

The two12-image contact sheets were manually inspected. This confirmed class semantics, mixed source sizes and Hard Hat full-body boxes. The full400images passed programmatic XML parse, decoded image dimensions, class-name and in-bounds positive-width/height checks with0issues. This is not exhaustive manual reannotation or a guarantee of label completeness.
