# 六模型精度、目标尺寸与跨来源诊断报告（S2–S6）

日期：2026-11-14。数值来自 `accuracy-matrix-1` 的真实 RK3568 NPU 检测转储；离线重算全部指标，没有训练、微调、剪枝、蒸馏或阈值搜索。**85% 精度目标没有通过；S6 仅给出待验收的性能/质量配置，不能据此宣称物理摄像头部署定型。**

## 结论与两种暂定配置

建议保留两种配置供真实场景验证：**响应优先使用 `helmet_416x416.rknn`；小目标质量优先使用 `helmet_640x640.rknn`**。两个建议保持操作置信度 `.25`、NMS `.45`，依据固定诊断样本作取舍，不调整阈值以追求通过。它们均须另行通过真实来源采集、实际显示和稳定性门槛；短时图片基准、文件回放和软件故障注入分别属于不同证据，不能替代物理摄像头验收。

2026-11-13 run2 原模型当次 E2E 均值为 **137.94 ms / 7.2 FPS**。这里使用该次 JSON 原始数值，没有使用日志末尾硬编码的旧 “141 ms / 7.1 FPS”。此基准对一张 1280×960 图片循环 50 次，预热 5 次，NPU governor 为 performance，结束回读恢复 rknpu_ondemand；它不是摄像头、显示、输出完成或 30 分钟稳定性测量。

## 样本、类别与指标口径

**模型 `person` 指裸头（未戴安全帽），`hat` 指戴帽头部，不能把整个人体当作裸头框。** SHWD 用源 `person→person`、`hat→hat`；HardHat 用 `head→person`、`helmet→hat`，35 个源 `person` 整体人体对象从规范化 GT 中明确忽略，没有并入裸头。

SHWD 是原始 VOC2028 测试列表前200 ID；HardHat 是固定 Kaggle API 文件列表前200标注。选择在推理前固定，未因预测结果更换样本；不是各来源全量评估。没有场景ID，两来源分别保留一个unknown-scene诊断组，没有虚构场景独立划分。SHWD 的七处文件名映射（6 unique-stem、1 case-insensitive）、原标注和图片哈希均按 manifest 校验。

AP 是项目 all-point **AP50**：IoU=.50、保留分数下限 `.001`，不是完整分数范围AP，不是官方COCO AP50:95，也不是标准SHWD/VOC difficult-ignore结果。P/R/F1 在操作阈值 `.25` 上计算；F1=2PR/(P+R)。同类别按分数排序，匹配最高IoU的可用GT。mAP为有GT类别AP的算术均值。尺寸按原始来源像素的GT框面积：small [0,32²)、medium [32²,96²)、large [96²,∞)。跨面积匹配及落在其他面积的未匹配预测按记录的area ignore规则处理，area P/R/F1不能与全图计数直接相加。HardHat large person没有GT，AP/R/F1保留N/A；该large mAP仅是hat AP，不能与双类别large mAP直接比较。

训练集独立性**未知**，SHWD还存在社区模型可能使用过该来源的风险。已确认 `shwd/000764.jpg` 与 `hardhat/hard_hat_workers1137.png` 为同一照片的缩放/反射填充版本；排除这一张只移除已知交叉来源重叠，不能证明与训练集独立。139 difficult帽作为正常GT保留，统计口径明确影响可比较性。

## 85%目标与验收边界

六模型SHWD mAP50最高为 80.18%，HardHat200最高为 82.34%，排除已知重叠的HardHat199最高为 82.43%。**以当前报告明确使用的双类别项目mAP50口径，85%数值门槛未达到；独立性门槛也未满足。** 个别hat AP或裸头召回超过85%不代表整体目标通过。学校最终目标定义仍须明确，此处不把单类最高数值代替整体要求；原 metrics 的 `accuracy_target_pass` 保留null，表示证据资格不足，并非通过。没有检测是未知证据，不能解释为人人戴帽。

本报告不加入仍在进行或另批次产生的30分钟NPU回放和新FP16/INT8转换结果；两者必须以各自实际结束的manifest、原始产物和独立验收记录为准。性能推荐不是量化精度损失结论。

## 证据完整性与重建

[run manifest](accuracy-matrix-1/run-manifest.json)记录12次顺序执行、每次退出状态、dump/metric哈希、模型与源码哈希、数据哈希及governor恢复。生成器重新校验全部12个dump为complete、每个200输入成功且0错误；验证400张实际图片、400份原标注哈希、200张完整预测键（含合法空预测），重算12组整体/面积/TPFPFN指标、成对跨来源差值和6组199张补充指标。失败dump不能充当空预测。
