# 项目阅读导航（v5-r3 交付版）

更新日期：2026-11-15。当前 tag 为 `native-app-v5-r3`；先从[项目交付说明](项目交付说明.md)了解成果、版本和验证范围，再按用途查阅资料。全部目录职责见[资料目录](README.md)。

本项目使用现成社区 YOLOv5 模型，在 RK3568 上实现本地安全帽头部检测、原帧时效校验、报警留痕与 Qt 常驻 App。日常检测无需开发板浏览器、电脑页面或持续外网；项目范围不包含训练、微调、剪枝或蒸馏。

## 在开发板上使用

从“安全帽检测”进入检测页，从“无线网络 / Wi-Fi 设置”进入无线页。已开始检测后，回桌面只隐藏界面，再点任一入口会复用同一会话；结束进程使用“退出应用”。具体按钮、状态和截图位置看[App 使用手册](app/板端App使用手册.md)，生命周期看[后台运行手册](app/板端App后台运行手册-v4.md)。

当前根为 `/userdata/helmet-validation/20261115-native-app-v5-r3-lan-3`。手机连接同一可互通内网，访问 `http://板端IP:8091/`；本板当前为 `192.168.1.3`。开机入口配置后台待机，板屏手动开始检测。详见[手机及开机指南](app/手机内网查看与开机启动-v5.md)。USB 相机采集节点 `/dev/video10`、metadata `/dev/video11`，使用 MJPG；新增设备按[现场步骤](field-validation/摄像头接入与现场验收.md)确认后刷新。

**已实现应用级离线运行。** 检测和 Qt 都在板端，需预装兼容 OS/runtime，手机仅需内网。完整新根核验见[v5 指南](app/手机内网查看与开机启动-v5.md)。实际重启后 App 使用已有记录，自动后台先于人工打开、实体手机、WiFi事务、U盘/OTA、独立供电和长期现场仍有各自门槛。

## 怎样核对一句结论

先从[实验索引](experiments/README.md)找到对应报告和 manifest，确认模型、输入、SHA、阈值、入口、计时范围及清理。本轮 [v5-r3](experiments/2026-11-15/app-lan-autostart/report.md)记录内网与 180.50 秒相机、init 和重复退出；历史 [Phase 1](experiments/2026-11-15/native-app-usability-v4-phase1-1/report.md)与 [Phase 2](experiments/2026-11-15/native-app-usability-v4-phase2-1/report.md)保留各自的物理/常驻证据。v2 30 分钟回放另行引用。

静态处理 FPS、采集 FPS、独立检测 FPS、输出 FPS 和实际显示 FPS 有各自计时边界。两套各 200 图数据只有诊断资格，训练重叠未知且有共同照片，最高 mAP50 低于 0.85；软件测试、短跑和演示文件不补成独立质量或长期现场通过。

GitHub 保存当前资料、清单与关键收据；大视频、原图、JSONL、`.runtime/`、`.superpowers/` 等完整载荷可能仅在本机。详见[资料目录中的保存范围](README.md#github-与本机资料)。旧初步文档、原开题、v1–v6 PPT 已移入[历史归档](archive/README.md)，原实验及开发计划保留记录时状态。
